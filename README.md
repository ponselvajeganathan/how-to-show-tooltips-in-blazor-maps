# How to Show Informative Tooltips in Blazor Maps

## Overview

This sample demonstrates tooltip customization in the Syncfusion [Blazor Maps](https://www.syncfusion.com/blazor-components/blazor-map) component within a hosted Blazor WebAssembly application. The implementation shows how map tooltips can be displayed when interacting with geographic elements and how tooltip content can be customized using HTML markup and template-based values. The sample also illustrates tooltip styling techniques that improve data presentation and provide richer contextual information without cluttering the map surface.

**Example**: https://blazor.syncfusion.com/demos/maps/tooltip?theme=bootstrap5

**Documentation**: https://blazor.syncfusion.com/documentation/maps/user-interactions#tooltip

## Key Features

- Demonstrates tooltip rendering within the Syncfusion Maps component.
- Shows how tooltip content can be displayed when users interact with map shapes and geographic regions.
- Demonstrates formatting tooltip content using HTML markup.
- Illustrates the use of custom template values inside tooltip content.
- Shows how tooltip appearance can be customized with colors and styling options.
- Demonstrates interactive geographic data presentation using tooltip-based information display.
- Uses tooltip content to provide detailed information without requiring additional UI components.
- Implements tooltip functionality within the Maps component hosted in `Client/Pages/Index.razor`.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file:

   `ShowTooltip.sln`

3. Restore NuGet packages.
4. Set the startup project 
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root or startup project directory.

```bash
dotnet restore
dotnet run
```
